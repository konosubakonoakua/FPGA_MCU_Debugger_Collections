# Raspberry Pi Pico Logic Analyzer

[中文](./readme.md) | **English**

## [gusmanb/logicanalyzer](https://github.com/gusmanb/logicanalyzer)

Very cheap logic analyzer based on a Raspberry Pi Pico:

- Up to **24 digital channels**, pre and post trigger sampling, edge trigger and pattern trigger up to 16 bits
- The most basic version is purely a Pico as-is: short GPIO0 and GPIO1, upload the firmware, and you're good to go
- The Pico only supports 3.3V; for diagnosing 5V signals the author also designed a fast level-shifter board
- Includes powerful host software (Windows only for now): visualize captured data, export captures, use protocol analyzers, etc.
