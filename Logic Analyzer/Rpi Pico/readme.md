# Raspberry Pi Pico 逻辑分析仪

**中文** | [English](./readme_en.md)

## [gusmanb/logicanalyzer](https://github.com/gusmanb/logicanalyzer)

基于 Raspberry Pi Pico 的超低成本逻辑分析仪：

- 最多 **24 个数字通道**，支持前置/后置触发采样，边沿触发和最高 16 位的码型触发
- 最基础的版本就是一块 Pico 本体：只需短接 GPIO0 和 GPIO1、上传固件即可使用
- Pico 仅支持 3.3V；如需诊断 5V 信号，作者还设计了快速电平转换板
- 附带功能强大的上位机软件（目前仅 Windows）：可视化采集数据、导出采集、协议分析器等
