# CY7C68013A Logic Analyzer

[中文](./readme.md) | **English**

> Open-source project: [UINIO-Logic-24MHz](http://www.uinio.com/Project/UINIO-Logic-24MHz/)

UINIO-Logic-24MHz is an open-source logic analyzer compatible with both the Cypress (now Infineon) CY7C68013A and the Corebai CBM9002A USB controllers.

## Specifications

| Item | Details |
|------|---------|
| **USB controller** | CY7C68013A / CBM9002A |
| **Channels** | 8 digital channels sampled simultaneously |
| **Max sample rate** | 24MHz per channel |
| **Logic level** | Up to 5.5V (>2V reads high, <0.8V reads low) |
| **Host software** | Sigrok PulseView (firmware loaded on the fly) or Saleae Logic (firmware pre-flashed) |
