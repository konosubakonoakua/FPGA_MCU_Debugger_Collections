# CY7C68013A 逻辑分析仪

**中文** | [English](./readme_en.md)

> 开源项目：[UINIO-Logic-24MHz](http://www.uinio.com/Project/UINIO-Logic-24MHz/)

UINIO-Logic-24MHz 是一款同时兼容赛普拉斯（已被英飞凌收购）CY7C68013A 和芯佰微电子 CBM9002A 两款 USB 控制器的开源逻辑分析仪。

## 规格

| 项目 | 详情 |
|------|------|
| **USB 控制器** | CY7C68013A / CBM9002A |
| **通道数** | 8 通道数字信号同时采集 |
| **最大采样率** | 单通道 24MHz |
| **逻辑电平** | 最高 5.5V（>2V 视为高电平，<0.8V 视为低电平） |
| **上位机** | Sigrok PulseView（可实时下载固件）或 Saleae Logic（需提前烧录固件） |
