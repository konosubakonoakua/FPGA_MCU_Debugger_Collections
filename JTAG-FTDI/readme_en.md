# Xilinx FTDI JTAG

[中文](./readme.md) | **English**

Xilinx FPGA JTAG debugger/programmer based on the FTDI FT2232HQ.

| Item | Details |
|------|---------|
| **Chip** | FTDI FT2232HQ |
| **Purpose** | Xilinx FPGA JTAG debugger/programmer |
| **Repository** | [hw-ftdi-jtag-xilinx](https://github.com/konosubakonoakua/hw-ftdi-jtag-xilinx) (Git submodule) |

## Fetching the submodule

`hw-ftdi-jtag-xilinx/` in this folder is a Git submodule; initialize it after cloning:

```bash
git submodule update --init
```
