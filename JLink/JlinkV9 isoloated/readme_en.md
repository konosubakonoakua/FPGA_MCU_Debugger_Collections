# J-Link V9 Isolated

[中文](./readme.md) | **English**

> Open-source project: [J-Link-V9-Base](https://oshwhub.com/travellium/J-Link-V9-Base) (by travellium, on oshwhub)

Isolated J-Link V9 base-board design (the folder name `isoloated` is a historical typo for "isolated").

## Files

| File | Description |
|------|-------------|
| `Jlink.zip` | Design resource pack |
| `bootloader.bin` | Bootloader firmware |
| [jlink-v9激活.txt](<./jlink-v9激活.txt>) | Activation commands + sample SN (note: file is GBK-encoded) |

> Activation procedure is the same as for [JlinkV9](<../JlinkV9/readme_en.md>).
