# J-Link V9 隔离版

**中文** | [English](./readme_en.md)

> 开源项目：[J-Link-V9-Base](https://oshwhub.com/travellium/J-Link-V9-Base)（作者 travellium，立创开源硬件平台）

带隔离的 J-Link V9 底板方案（文件夹名 `isoloated` 为历史拼写，实为 isolated）。

## 文件

| 文件 | 说明 |
|------|------|
| `Jlink.zip` | 设计资料包 |
| `bootloader.bin` | Bootloader 固件 |
| [jlink-v9激活.txt](<./jlink-v9激活.txt>) | 激活命令 + 示例 SN（注意：文件为 GBK 编码） |

> 激活步骤与 [JlinkV9](<../JlinkV9/readme.md>) 相同。
