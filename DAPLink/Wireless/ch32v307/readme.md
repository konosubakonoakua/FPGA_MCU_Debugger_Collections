# 无线 DAPLink（CH32V307 + SX1281）

**中文** | [English](./readme_en.md)

> 开源项目：[dap_hs_wl_v0-4](https://oshwhub.com/ylj2000/dap_hs_wl_v0-4)（作者 ylj2000，立创开源硬件平台）

基于 CH32V307RCT6 + SX1281 无线模块的 DIY 无线调试器，总成本不到百元，性能媲美 300+ 元的商业无线调试器。

> 💡 更新的设计见 [ch32v208](../ch32v208/readme.md)（本仓库推荐版本）。

## 背景

调试会动或有一定危险性的目标（机器人、电源等）时，希望电脑离目标远一点。长 USB 线麻烦且距离有限；市面上的无线调试器良莠不齐，速度慢、连接不稳定的很多，好用的又很贵（300+ 元）。本项目通过多版迭代得到一个 DIY 无线调试器的合适方案。

## 规格

| 项目 | 详情 |
|------|------|
| **主控** | CH32V307RCT6 (RISC-V) |
| **无线** | SX1281 无线模块 |
| **接口** | SWD + JTAG + 虚拟串口 (VCP) |
| **复位** | 硬件复位 + 软件复位 |
| **成本** | 总计不到百元 |
| **驱动** | Win10 及以上免驱，即插即用 |

## 使用方式

一套无线调试器分为发送端（Host）和接收端（Slave），两端软硬件完全一致：

- 通过按键或上位机进行配对、模式切换、调节参数。
- 支持调试 ARM 单片机（STM32、GD32 等）。
- 除无线模式外可切换到有线模式（USB），适合无线环境复杂的场合临时使用，性能比无线模式强。

## 指示灯

| 颜色 | 模式 |
|------|------|
| 红色 | 有线模式 (USB) |
| 蓝色 | 无线发送端 (Host) |
| 绿色 | 无线接收端 (Slave) |

| 状态 | 含义 |
|------|------|
| 呼吸灯 | 正常连接 |
| 慢闪 | 无线另一端未就绪（未上电或未配对） |
| 快闪 | 下载调试中或虚拟串口有数据 |
