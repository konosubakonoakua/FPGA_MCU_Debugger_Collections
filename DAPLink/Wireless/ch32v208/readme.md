# 无线 DAPLink（CH32V208 / CH32V305）

**中文** | [English](./readme_en.md)

> 开源项目：[dap_v208_v305_open](https://oshwhub.com/ylj2000/dap_v208_v305_open)（作者 ylj2000，立创开源硬件平台）

新一代无线 DAPLink 调试器，**本仓库无线 DAPLink 方案中的推荐版本**。

## 规格

| 项目 | 详情 |
|------|------|
| **主控 (FS 版)** | CH32V208，BOM 成本约 10 元/pcs |
| **主控 (HS 版)** | CH32V208 + CH32V305，BOM 成本约 18 元/pcs |
| **接口** | SWD + JTAG + 虚拟串口 (VCP) |
| **复位** | 硬件复位 + 软件复位 |
| **无线距离** | 2M 空中速率 + 板载天线实测 100m+；降低空中速率或外接天线预计可达 1km+ |
| **驱动** | Win10 及以上免驱，即插即用 |

## 版本说明

- FS 版与 HS 版 **PCB 完全一致**，仅焊接元件不同。
- 另有与鼠标接收器同尺寸的 Mini FS 版，性能与 FS 版一致。
- HS 版主要在刚需 DAP V1 协议的场景（老版本 MDK、Ozone 等）有 3 倍以上性能提升；仅主机用 HS、从机用 FS，性能与双 HS 无区别。
- FS 版建议在 MDK ≥ 5.29、IAR ≥ 8.32 下使用，以避免 USB FS + DAP V1 协议导致性能差。
- 有线、无线性能均远超前两版（[ch32v307](../ch32v307/readme.md)、[esp32s3](../esp32s3/readme.md)）：有线性能远超 J-Link V9，无线性能远超 ST-LINK V2，且延迟低，Debug 体验流畅。

## 使用方式

一套无线调试器分为主机（master）和从机（slave），两端软硬件完全一致：

- 连接 USB 识别为 U 盘进行配置，也可通过按键进行配对、模式切换。
- 支持调试 ARM 单片机（STM32、GD32 等），支持对 ESP32 进行无线下载。
- 除无线模式外可切换到有线模式（USB），适合无线环境复杂的场合，性能比无线模式更强。
- 采用自研跳频算法，稳定性和速度理想。

## 指示灯

| 颜色 | 模式 |
|------|------|
| 红色 | 有线模式 (USB) |
| 蓝色 | 无线主机 (master) |
| 绿色 | 无线从机 (slave) |

| 状态 | 含义 |
|------|------|
| 呼吸灯 | 正常连接 |
| 慢闪 | 无线另一端未就绪（未上电或未配对） |
| 快闪 | 存在数据传输 |
