# 无线 DAPLink（ESP32-S3）

**中文** | [English](./readme_en.md)

> 开源项目：[dap_hs_esp_open](https://oshwhub.com/ylj2000/dap_hs_esp_open)（作者 ylj2000，立创开源硬件平台）

基于 ESP32-S3 的廉价无线调试器，成本约 30 元，性能接近上一版百元方案（[ch32v307](../ch32v307/readme.md)）。

> 💡 更新的设计见 [ch32v208](../ch32v208/readme.md)（本仓库推荐版本）。

## 背景

市面上的无线调试器大多基于 CMSIS-DAP 协议，但性能和价格相差巨大，很多以低廉的成本、极差的性能卖着极高的价格。上一版基于 CH32V307 + SX1281 的方案成本已不到百元，本项目目标是更廉价、性能仍满足一般使用的方案。

## 方案选型

- HID 模式的 DAP 无法达到目标速度，必须使用基于 **WinUSB 的 Bulk 模式**。
- 出于成本考虑选择自带 USB + 无线的单片机：
  - ESP32-S2：TinyUSB 占用过多 CPU 资源，有线速度仅 40+ KB/s，弃用。
  - **ESP32-S3**：双核设计，任务分配到两个核心后有线速度 90 KB/s 以上，最终选定。

## 规格与性能

| 项目 | 详情 |
|------|------|
| **主控** | ESP32-S3（双核） |
| **USB 模式** | WinUSB Bulk（非 HID） |
| **无线** | WiFi 信道 |
| **有线速度** | 约 95 KB/s（MDK + STM32F4 Program 速度） |
| **无线速度** | 最高约 45 KB/s，一般无线环境下约 40 KB/s |
| **成本** | 约 30 元 |

> 上一版（CH32V307）参考：有线 98 KB/s、无线 48 KB/s。本版以约十分之一于商业产品的价格达到接近的性能。
