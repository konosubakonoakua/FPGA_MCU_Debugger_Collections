# CH552 DAPLink

**中文** | [English](./readme_en.md)

> 开源项目：[wagiminator/CH552-DAPLink](https://github.com/wagiminator/CH552-DAPLink)

基于 CH552 单片机的 CMSIS-DAP 调试器：

- 遵循 CMSIS-DAP 标准，支持 **SWD 和 JTAG** 协议
- 可用于 Microchip SAM 及其他 ARM 单片机的编程调试
- 附带**虚拟串口 (VCP)**，提供额外调试能力
- SWD 固件源自 Ralph Doncaster 的 CH55x DAPLink 实现以及 Deqing Sun 的 CH55xduino 移植

详见项目主页：<https://github.com/wagiminator/CH552-DAPLink>
