# CH552 DAPLink

[中文](./readme.md) | **English**

> Open-source project: [wagiminator/CH552-DAPLink](https://github.com/wagiminator/CH552-DAPLink)

CMSIS-DAP debugging probe based on the CH552 microcontroller:

- Follows the CMSIS-DAP standard, supports both **SWD and JTAG** protocols
- Suitable for programming Microchip SAM and other ARM-based microcontrollers
- Includes a **Virtual COM Port (VCP)** for extra debugging capability
- SWD firmware derived from Ralph Doncaster's DAPLink implementation for CH55x, along with Deqing Sun's CH55xduino port

See the project page: <https://github.com/wagiminator/CH552-DAPLink>
