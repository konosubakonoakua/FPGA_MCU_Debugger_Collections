# Infineon MiniWiggler

**中文** | [English](./readme_en.md)

> 开源项目：[三合一下载器](https://oshwhub.com/xljxlj/san-he-yi-xia-zai-qi)（作者 xljxlj，立创开源硬件平台）

英飞凌 MiniWiggler 三合一下载器复刻，原理图参考英飞凌官方开发板板载下载器。

> 可商用（需保留主板上作者名并附带开源链接），支持修改后二创。

## 特性

- 全 PCB 结构，使用铜柱装配，符合 JLC 白嫖工艺（白嫖请选 1.0mm 板厚，便于剪切）
- 支持 **DAP 下载和 JTAG 下载**，另有独立串口接口
- 带过流保护、ESD 保护，支持外部 IO 电压
- 固件在附件，使用 **FT_Prog** 烧录
- 注意：简牛座沉板安装，需剪脚

## RGB 指示灯

| 颜色 | 状态 |
|------|------|
| 红色 | 上位机控制断电 / USB 未连接电脑 / 负载过流保护 / 无外接供电 |
| 绿色 | 连接状态 |
| 蓝色 | 仿真中 |

## 开关说明

| 开关 | 功能 |
|------|------|
| 右上角开关 | 切换逐飞 / 龙邱核心板调试串口定义 |
| 左下角第一个开关 | 切换 IO 电压：内置 3.3V / 外置供电 |
| 左下角第二个开关 | 切换 JTAG / DAP 下载模式（JTAG 和 DAP 下载接口分开，需接不同接口） |
