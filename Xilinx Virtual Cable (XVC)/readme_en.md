# Xilinx Virtual Cable (XVC)

[中文](./readme.md) | **English**

Xilinx Virtual Cable (XVC) is a protocol for JTAG debugging of Xilinx FPGAs over the network. Related open-source projects below.

## [xvc-pico](https://github.com/kholia/xvc-pico)

Raspberry Pi Pico based Xilinx Virtual Cable:

- Lets a Pico (and Pico 2) act as a JTAG adapter for programming Xilinx FPGAs

![](https://github.com/kholia/xvc-pico/raw/ng/pinout.png)

## [jtag-remote-server](https://github.com/jiegec/jtag-remote-server)

Remote chip-debugging tool:

- Uses libftdi to communicate with FTDI chips
- Exposes various protocols for remote debugging
